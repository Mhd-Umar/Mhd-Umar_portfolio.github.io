Student module

  • Submit complaints and suggestions, and track complaint status

Resource analyzer

Current project, in progress

AI-Based Ransomware Early Detection and Warning System

A Windows tool that catches ransomware by its behaviour while it is encrypting files, warns the user and can stop the process. It runs fully on one PC.

Built with

PythonwatchdogNumPyscikit-learnSHAPpsutilStreamlit
1

Watch. Monitor file changes, entropy jumps, extension changes, honeyfiles and shadow copy deletion attempts.

2

Score. An AI risk score from 0 to 100 using Isolation Forest and One-Class SVM, with SHAP to explain why.

3

Respond. Show an alert with Kill Process, Investigate or Ignore, suspend or kill with psutil, and a Streamlit dashboard of the timeline and alert history.
